# Module 1 - Generic Bite-Size Notes

## Module goal

Understand why Splunk exists before going deep into SPL.

Splunk helps organizations use machine data to investigate, monitor, alert, report, and make operational decisions.

---

## Bite 1 - Machine data

Machine data is data automatically generated by systems, applications, devices, networks, servers, cloud services, and other technology.

Examples:

```text
application logs
server logs
authentication events
firewall events
database logs
web access logs
error logs
transaction events
device events
```

Key idea:

> Machine data is the evidence trail created by technology.

---

## Bite 2 - Why machine data is hard

Machine data can be hard to use because it may come from many sources and many formats.

Some data is structured.  
Some is semi-structured.  
Some is unstructured.

This makes it difficult to understand manually.

Key idea:

> The value is high, but the raw form can be messy.

---

## Bite 3 - Operational intelligence

Operational intelligence means using machine data to understand what is happening across an organization and respond to issues.

Without operational intelligence, teams may guess, escalate blindly, or investigate in isolation.

With operational intelligence, teams can search, correlate, and act based on evidence.

Key idea:

> Operational intelligence turns machine data into useful investigation evidence.

---

## Bite 4 - Incident triage

A generic incident pattern:

```text
User reports a problem
Support confirms the symptom
Technical team searches events
Related events are correlated
Likely cause is identified
Correct team responds
```

The important point is not the story.  
The important point is the pattern.

Key idea:

> Searchable machine data reduces investigation time.

---

## Bite 5 - What Splunk does

Splunk helps users:

```text
collect machine data
index machine data
search data
analyze events
visualize results
save reports
create dashboards
trigger alerts
organize knowledge with data models
```

Key idea:

> Splunk makes machine data available, accessible, and usable.

---

## Bite 6 - Index

An index is where Splunk stores ingested machine data so it can be searched.

Simple idea:

```text
data source -> ingestion -> index -> search
```

Key idea:

> If data is in an index, Splunk can search it.

---

## Bite 7 - Reports and dashboard panels

A report is a saved search result that can provide repeated insight.

A dashboard panel is one visual block on a dashboard. It usually displays one specific view of data, such as a count, table, chart, trend, or alert-related result.

Simple idea:

```text
search -> result -> report -> dashboard panel
```

Key idea:

> Reports and dashboard panels make search results reusable and visible.

---

## Bite 8 - Data models and Pivot

A data model organizes knowledge into structured datasets.

Pivot lets users visualize structured data from data models without writing every custom SPL search.

Key idea:

> Data models and Pivot help make analysis easier for users who may not write SPL deeply.

---

## Bite 9 - Alerts

Alerts notify teams when defined conditions occur.

Generic examples:

```text
too many failed logins
transaction failures increase
server errors spike
response time becomes slow
security event appears
```

Key idea:

> Alerts help teams respond sooner.

---

## First generic SPL examples

```spl
error
```

Searches for events containing the word `error`.

```spl
failed login
```

Searches for events containing the words `failed` and `login`.

```spl
failed transaction
```

Searches for events related to failed transactions.

These are intentionally simple. Module 1 is about purpose and investigation mindset, not advanced SPL.

---

## Module 1 durable summary

Machine data is automatically generated evidence from technology.

Splunk helps collect, index, search, analyze, visualize, report, and alert on that evidence.

Operational intelligence means using that evidence to understand and respond to what is happening across the organization.

The goal is to move from guessing to evidence-based investigation.
