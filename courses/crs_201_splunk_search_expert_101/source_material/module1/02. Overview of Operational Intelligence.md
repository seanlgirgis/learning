​Let's take a look at a scenario from Buttercup Games, ​a fictional gaming company with offices across the globe. ​Last week, a customer called support ​to report having an issue ​purchasing in-game upgrades for their product ​Puppies vs. Zombies. ​The support console showed ​that everything should be working correctly, ​so Tina escalated the issue ​to Matt in application support. ​Matt checked all his monitoring tools, ​and came up empty-handed, ​so he escalated the issue to Richard, the developer. ​Richard stopped his work on "Puppies vs. Zombies 2" ​to look at his code and run some tests. 
​Not seeing any issues, ​he got Sue, the system administrator involved. ​Sue stopped what she was doing ​to help Richard sift through the application, ​web server, and point-of-sale server logs. ​They established it was not an application error, ​so they escalated it to Erin, the database administrator. ​Erin started going through the SQL logs. ​She found a slow query ​making it hard for some users to complete their transactions. ​At this point nearly nine hours had passed, ​and while the issue was found, ​it still needed to be fixed, ​and that was just one issue that popped up that day. ​Now, let's see how Buttercup Games ​could have used their machine data ​to solve this issue in less time. 
​When the initial support call comes in to Tina, ​it is logged for future use. ​Tina dispatches the call to Matt. ​Matt searches the data for events ​where purchase attempts end in an error. ​He pinpoints an event that matches the user's experience. ​That event can be tied to a database query. ​Which can be correlated to an entry in the slow query log. ​Allowing Matt to escalate to Erin in a matter of minutes ​without getting anyone else involved. 
​Taking it one step further... ​What if we could alert when transactions fail, ​even before the customer calls tech support? ​If we had some way to pinpoint, correlate, ​and alert on specific events, ​we could save our fellow employees many hours and headaches. ​This is where Splunk comes in. ​Simply put, Splunk can take any data ​and add it to an intelligent, searchable index. ​Adding structure to unstructured data ​and allowing you to extract all sorts of insights into your business. ​Not just application issues, but security, user behavior, ​hardware monitoring, sales totals, ​whatever you can think of doing.
